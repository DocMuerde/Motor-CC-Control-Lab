## English

Lab session guides for DC motor control, adapted for the rig.  

- [PDFs](pdfs/) for reading or distributing the lab guides.
- [Data](data/) for experiment recordings, organised by lab.
- [Sources](sources/) for LaTeX and figures, organised by lab.

### Index

| Lab | Title | Objectives |
|---|---|---|
| [Lab 01](pdfs/lab01_isa.pdf) | System identification | Measure the PWM–speed curve, choose an operating point, and identify the dynamics with a local step |
| [Lab 02](pdfs/lab02_isa.pdf) | PID position control | Design and tune a discrete PID controller; analyse the influence of Kp, Ki, Kd parameters on the response |
| Lab 03 (planned) | State-space control | Pole placement via state feedback; design of a Luenberger observer |
