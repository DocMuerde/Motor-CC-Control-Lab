# Prácticas de laboratorio / Lab Sessions

## Español

Guiones de prácticas de control adaptados al equipo de motor CC.

### Índice

| Práctica | Título | Objetivos |
|---|---|---|
| [Lab 01](lab01/) | Identificación del sistema | Obtener el modelo dinámico del motor por respuesta al escalón; estimar la constante de tiempo y la ganancia estática |

## English

Lab session guides for DC motor control, adapted for the rig.  
Each lab includes a student guide, report template, and MATLAB scripts.

### Index

| Lab | Title | Objectives |
|---|---|---|
| [Lab 01](lab01/) | System identification | Obtain the motor dynamic model from a step response; estimate the time constant and static gain |
| [Lab 02](lab02/) | PID position control | Design and tune a discrete PID controller; analyse the influence of Kp, Ki, Kd parameters on the response |
| [Lab 03](lab03/) | State-space control | Pole placement via state feedback; design of a Luenberger observer |
