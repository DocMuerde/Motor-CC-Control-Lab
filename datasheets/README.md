## English

Place the official technical documents for each component here.

### motor/
Datasheet for the **maxon A-max 22** motor (Art. 110120) and the 3D CAD model of the motor + gearbox assembly.

### encoder/
Datasheet for the **ams AS5047P** — 14-bit high-resolution magnetic rotary position encoder.  
Official download: https://ams-osram.com/products/sensors/position-sensors/ams-as5047p-high-resolution-rotary-position-sensor  
Key parameters: 14 bits (16 384 steps/rev), SPI/ABI/PWM/UVW interfaces, 3.3 V, −40 °C to +150 °C.

### driver/
Datasheet for the **Toshiba TB6612FNG** chip and schematic for the **SparkFun ROB-14451** breakout board.  
Continuous current 1.2 A per channel, 3.2 A peak. Maximum PWM frequency 100 kHz.

### reductora/
Datasheet for the **maxon GP 22 B** planetary gearbox (Art. 110356) coupled to the motor.
