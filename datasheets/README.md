## English

This folder contains technical documentation and CAD files for the components of the DC motor control lab rig. The documents are already included in the repository and can be opened using the links below.

### Driver — Toshiba TB6612FNG and SparkFun board

[`driver/`](driver/) contains the integrated circuit datasheet and the SparkFun board design documents:

- [TB6612FNG datasheet (Toshiba, PDF)](driver/TB6612FNG-Datasheet-Toshiba.pdf).
- [SparkFun board schematic, version v11c (PDF)](driver/SparkFun_Motor_Driver-TB6612FNG_v11c.pdf).
- [Eagle design files](driver/SparkFun_Motor_Driver-TB6612FNG_v11c/): `.sch` schematic and `.brd` board layout.

The rig's ISA shield design is stored separately in [`hardware/pcb/`](../hardware/pcb/).

[`encoder/`](encoder/) contains:

- [AS5047P datasheet (PDF)](encoder/AS5047P-Datasheet.pdf).
- [Encoder image](encoder/AS5047P.png).
